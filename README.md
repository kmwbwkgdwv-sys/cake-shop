# ケーキ屋さんシミュレーター

最大4人で1つのお店を共同経営する、**一人称視点・横画面**のパティスリー経営シミュレーションです。
YouTube でよく実況されている「Fast Food Simulator」系の作業シミュレーターのように、広い厨房を自分で歩き回り、
家具を好きな場所に並べ、材料の段ボールを運んで棚にしまい、棚から材料を手に取ってミキサーで生地を作り、オーブンで焼き、
クリームを泡立て、いちごを1つずつ置いて仕上げ、カウンターのガラスのショーケースに並べ（ホールのまま／ケーキナイフで6等分にしてカット）、レジで注文を受けて箱（店内はお皿）に詰めて手渡し、
お会計（現金はお釣りを選んで渡す／カードはタッチ）、使ったお皿や型を洗います。売るほど「店舗レベル」が上がり、新しいお菓子・上位の設備・家具・アルバイト・増床が解放されていきます。

- 静的サイトなので GitHub Pages にそのまま置けます（ビルド不要・外部ライブラリなし。3D は自前の WebGL）
- オンライン機能（共同経営・引き継ぎコード・データ同期）は Firebase Realtime Database を使います
- Firebase を設定しなくても、ひとりで遊べます（データはその端末だけに保存）

## 遊び方

| 操作 | PC | スマホ・タブレット（横向き） |
| --- | --- | --- |
| 移動 | W A S D（Shift で小走り） | 左下のスティック（倒しきると小走り） |
| 見回す | マウスを動かすだけ（ボタンを押さなくてOK。画面の端に寄せると回り続ける） | 画面の右側をスワイプ |
| つかむ・置く・材料を入れる（長押しで続けて） | E / Space / 左クリック | 大きいボタン |
| 使う（全部取る・ミキサーを回す・電源・塗る・洗う・仕上げる） | F / 右クリック | 小さいボタン |
| 捨てる・落とす・ボウルを空ける | Q | ゴミ箱ボタン |
| 家具の配置モード | B | 「配置」ボタン |
| パソコン／レシピ帳／スタンプ | Tab / R / T | 画面のボタン（パソコンはパソコン室の机） |

画面中央の照準（・）の先にあるものが操作の対象です。照準の下に「できること」が表示されます。
設定画面で「視点の感度・上下反転・視野角（FOV）・画面の揺れ・マウスを画面に固定する FPS 方式・ボタンの大きさ・左右配置・ボタン位置（ドラッグで自由配置）・軽量モード・画質の自動調整」を変えられます。

- **スマホは横画面専用**です。縦向きのときは「横向きにしてね」と表示されます（Android の Chrome などは入店時に全画面＋横向き固定になります）
- **ほかのアプリの音楽を止めません**。効果音は Web Audio だけで鳴らし、iPhone / iPad（iOS 16.4 以降の Safari）では Audio Session を「ambient」にしているので、
  Spotify や YouTube などの BGM を流したままでも、BGM と効果音の両方が途切れずに鳴ります（※ iPhone ではマナーモード中は効果音が鳴りません）
- **グラフィック**：天井照明・ペンダントライト・商品棚の照明、厨房のタイル壁・ガラス扉の冷蔵庫、やわらかい影、光のにじみ（ブルーム）、なめらかな輪郭（FXAA）、金属や大理石への映り込みで仕上げています。軽量モードではこれらを省いて軽くします
- **重い端末では画質を自動で下げます**（影・仕上げ処理・解像度を段階的に減らす。設定 → 表示・音 で切り替え／標準に戻せます）。
  スマホでメモリが足りなくなって 3D 表示（WebGL）が落ちた場合も、画質を1段下げて自動で作り直すので、画面が固まったままになりません。
  通信が切れて時間が止まっているときは、画面上部にそう表示されます
- **新しいお店を始めるとチュートリアル** が始まります：パソコンで家具を買う → 材料と箱を注文 → トラックから大きな段ボールを運んで展開 → 材料を棚へ → 生地 → 焼く → クリーム → デコ → ショーケース → ケーキナイフで切る → OPEN → 注文 → 箱に入れて渡す → レジでお会計 → 洗い物、まで画面右上の「やること」で1つずつ案内します。
  行き先には **ピンクの目印**（画面の外なら端に矢印）が出て、ミキサーでは「次は卵（あと2つ）」のように次に入れる材料まで教えてくれます。「とばす」で1手順ずつ飛ばせます。設定 →「遊び方を見る」でもう一度最初から
- **レシピはいつでも見られます**：「レシピ」ボタン（R キー）でレシピ帳。レシピ帳の「メモに出す」で、画面左上に **レシピメモ** をずっと出しておけます（‹ › でレシピを切りかえ、− でたたむ）。
  メモには混ぜる順・個数・焼く温度・クリーム・トッピングが出て、近くのミキサー・クリーム台に入れた材料には ✓ がつきます
- **お店の外には町の風景** があります（向かいの家並み・お店・街路樹・電柱・行き交う車や人。外には出られません。軽量モードでは車と人を省きます）

### お店の間取り（縦長。奥に広い厨房）
- お店は **間口が狭く奥行きが深い** 縦長の形。入口から入ると売り場、その奥がカウンター、カウンターの向こうに **広い厨房**（4人で動き回れる広さ）
- **カウンター** は途中で壁に仕切られていて、売り場側に出ているのは右側だけ。ここに **ガラスのショーケース** とレジを置きます
- **厨房**：家具は全部 **自由に動かせます**。カウンターの左の端の通路から売り場に出られます
- **倉庫**（奥の左・広め）：最初の **冷蔵棚・冷蔵庫・棚** が置いてあります（どこに置き直すかは自由）。左の壁の **裏口** から路地（トラックが来る所）に出られます
- **パソコン室**（奥・倉庫のとなり）：パソコン（仕入れ・家具・経営）。家具は置けないので、いつでも入れます
- **売り場**：カウンター・ショーケース・レジ・イートインのテーブル、入口の外に OPEN / CLOSE の看板

### 家具と配置（みんなで楽しく並べる）
- 最初にあるのは **机1・棚1・冷蔵棚1・冷蔵庫1・クリーム台1・ショーケース1・洗い場1・レジ1・ゴミ箱1**、それに **ケーキの型1つ・お皿1枚・ケーキナイフ1本**。**材料は何もありません**
- オーブン・ミキサー台・デコ台などは **パソコンの「家具・道具」** で買います（チュートリアルで最初に買います）。棚・冷蔵棚・在庫棚・冷蔵庫・ショーケース・商品棚（常温）・机・冷却ラック・レジも買い足せます。お皿・ケーキの型・ケーキナイフは1回で1つずつ買えます
- **買った家具はトラックで配達されます**（材料と同じトラック。配達中に追加で買った物・注文した材料は同じトラックに積んでくれます）。家具は **大きな段ボール** に入っていて、トラックが着くと運転手さんが荷台の横に下ろしてくれます。
  大きな段ボールを持つと、照準の先の床に **家具の形の影（緑＝置ける／赤＝置けない）** が出るので、置きたい所をねらって「ここに展開する」（「向きを変える」で 90° ずつ回せる）。大きな段ボールは棚には置けません
- **「配置」ボタン（B キー）** で配置モード：家具をねらって「動かす」→ 置きたい床をねらって「ここに置く」。「向きを変える」で 90° ずつ回せます。
  厨房と倉庫の中ならどこでも置けます（壁・ドアの前・通路・ほかの家具とは重ならないように、緑＝置ける／赤＝置けない）。レジはカウンターの上で左右に動かせます
- **棚の中は自由**：どこに何を置くかは自分で決めます。1つ置くとそこはその物の場所になり（同じ物だけ重ねられる）、全部取るとまた何でも置けます
- **棚の1枠に置けるのは10個まで**（材料・箱・お皿・ケーキの型など。手に持てる材料も10個まで）。1箱＝10個なので、1箱で1枠うまります
- 棚は6か所、冷蔵棚も6か所、机は4か所、冷蔵庫はケーキ6ホール
- **倉庫の拡張**（パソコンの「拡張」タブ）：店舗レベルが上がると、倉庫を手前に 1.3m ずつ広げられます（Lv2 ¥25,000 → Lv4 ¥60,000 → Lv6 ¥120,000 の3段階）。棚・冷蔵棚・冷蔵庫を置ける場所が増えます。広げた壁にかかる家具や段ボールは、近くの空いている所へ自動で移ります
- **ショーケース**：ケーキ屋さんでよく見る、ガラス越しにケーキが見える冷蔵ショーケース。カウンターの上に置き（左右に動かせる）、**3段×1段に3ホール＝9ホール** 並べられます。横に少し長め。最初は1台。買い足すとカウンターに並べられます

### お店の営業（OPEN / CLOSE）
- お店は最初 **CLOSE**。CLOSE のあいだは **お客さんが来ず、時計も止まります**。ゆっくり仕込みや模様替えができます
- 入口の外にある **看板（A型スタンド）** をねらって「OPEN にする」とお客さんが来て時計が進みます。いつでも CLOSE に戻せます
- 時計は 10:00〜20:00（OPEN の時間だけで約8分）。20:00 になるか、CLOSE 中に「今日は閉店」で日報（売上・原価・廃棄・家賃・光熱費・人件費・利益）が出て次の日へ

### お菓子づくり（全部自分の手で。みんなで分担すると早い）
1. **注文**：パソコン室のパソコンで材料と **ケーキの箱** をえらんで **カートに入れる**（1回10箱まで・カートでは1つずつキャンセル可）→ **発送**（送料 ¥500）→ 約9秒で **トラックが裏の路地に到着** → **倉庫の裏口** から外に出て、**荷台の中の段ボール** を持つ → **開ける** → 好きな棚の空いている所に **置く**（1つずつ／置けるだけ）。全部下ろすとトラックは帰ります
   - **段ボールのままは棚・冷蔵棚に入りません**（開けて中身を並べる）。段ボールごと置けるのは **在庫棚**・**机の上**・**床**
   - **在庫棚**（パソコンの「家具・道具」で ¥10,000）：段ボールのまま保管できる棚。**2列×2段で1台に段ボール4つまで**。開けた段ボール・空の段ボールも置けます。常温なので、要冷蔵の材料の段ボールは早めに冷蔵棚へ
   - **床に置く**：段ボールを持って床をねらうと、置く場所に枠が出ます（緑＝置ける／赤＝置けない）。ほかの物をねらっているときや前を向いているときも、Q（スマホはゴミ箱ボタン）で足もとの少し先に置けます。厨房・倉庫の中と、裏の路地（トラックと建物のあいだ）に置けます。ドアの前・通路・家具の上・トラックの所・荷おろしの場所には置けません。置いた段ボールはねらって「持つ」で拾えます（ぶつかるので通り道はあけておこう）
   - 開けた段ボールは「段ボールを閉じる」で **閉じられます**。**空の段ボール** もゴミ箱に捨てずに、床や机にそのまま置いておけます
   - 家具の大きな段ボールも、持ったまま「段ボールのまま床に置く」（Q／ゴミ箱ボタン）で、展開しないで床に置いておけます
2. **生地**：棚の材料をねらって「1つ取る」（長押しで続けて／「全部取る」も）→ ミキサーをねらって **順番どおり** に入れる。取りすぎたら棚に「1つ戻す」→ ミキサーを回し、ゲージが **緑** で止める（早いとダマ、遅いと生地がだれる）
3. **型に流す**：きれいな **ケーキの型** を棚から持ってきて、ミキサーをねらって「型に流す」（ミキサーの横の型置きに置いておいてもOK）
4. **焼く**：オーブンの電源を入れて予熱（温度は生地ごとの適温）→ 型を入れる → ゲージの緑で取り出す（生焼け・焦げは欠点として残る）
5. **冷ます**：机や冷却ラックに置く（温かいままデコするとクリームが溶ける）
6. **クリーム**：クリーム台に材料を入れて泡立て、緑で止める（泡立てすぎると分離）→「すくう」
7. **デコ**：冷めたスポンジをデコ台の回転台にのせる（**空いた型は汚れて手に残る** → 洗い場へ）→ クリームを持って「塗る」→ **画面を押したまま指（マウス）でなぞって** 上面と側面にまんべんなく塗る → 棚からトッピングを取ってケーキの上をねらって1つずつ置く（まちがえたら「1つ取る」で手に戻せる）→「仕上げる」
8. **並べる**：できたケーキは **ホール（切っていない1台）** です。持って **ショーケース** の空いている所に置くと、ホールのまま並びます。クリームのケーキは冷蔵のショーケース、クッキーなどの焼き菓子は **常温の商品棚** でもOK
9. **切る**：**ケーキナイフ**（最初に1本。パソコンで買い足せる）を持ってケーキをねらうと「ケーキナイフで6等分に切る」。**台の上ならどこでも切れます**（机・棚・ショーケース・デコ台の上・お皿の上）。
   机に置いたお皿にケーキをのせることもでき、お皿の上で切って取り分けると、最後に汚れたお皿が残ります。冷蔵庫の中では切れません
10. **接客**：レジで注文を受ける → **持ち帰りは箱**（ケーキの箱の山から1つ取る）、**店内で食べる人はお皿** を持って、切ったケーキから1切れずつ入れる → お客さんに渡す。
   **ホールの注文** は、空の箱を持って切っていないケーキをねらい「ホールのまま箱に入れる」（ホールは1箱に1台。まちがえたら空いている台に「ホールを箱から出して置く」）
11. **お会計**（商品を渡したあと、お客さんがレジに来ます）：**カード** はレジをねらって「タッチ」するだけ。**現金** はお預かりした金額からお釣りの **硬貨・お札をえらんでトレーにのせて渡す**（足りないと渡せない。多く渡すと損）。お会計をしないで待たせすぎると、お客さんは商品を置いて帰ってしまいます
12. **洗い物**：使ったケーキの型・店内で食べ終わったお皿（席に残る）は **洗い場の流し** に入れて「洗う」→ スポンジで **こすって泡だらけ** にする →「水を出す」で流す → 棚か水切りかごに置くと **30秒で乾きます**（ぬれたお皿・型は使えない）。**お皿は落とすと割れます**

### 注文とショーケース（ホール／カット）
- ケーキは **カット（1切れ）** でも **ホール（切らずに1台）** でも売れます。値段はパソコンの「販売価格」で別々に決められます（ホールの相場は 1切れの相場×6切れ×0.9 くらい。ホールは少しお得）
- お客さんは **販売中（ON）の、解放済みの商品** から好きな数（持ち帰りは1人6個まで・店内は3個まで）を選んで注文します。ショーケースに並んでいない物も注文されます
- **ホールで買うお客さん**：お祝いのお客さん・親子連れ・ご年配がよく買います（持ち帰りで1台）。ホールの値段が高すぎるとホールは買われません。クッキー・マドレーヌなどの焼き菓子は袋・個で売るのでホールはありません
- 注文票には「ホール」「カット」が分かれて出ます。ショーケースのホールを切れば足りるときは「ホールを切る」、足りないときは「あと○つ作る」「あと○台作る」と出ます
- **店舗レベルが上がるほど、お客さんが来るペースが上がり（Lv1 ×0.8 → Lv10 ×1.88）**、Lv4・Lv7 から1人あたりの注文（まとめ買い・ホール）も増えます。お店の混雑の上限も少しずつ上がります
- 空いている席があると、**店内で食べる** お客さんも来ます（お皿で出す。食べ終わると汚れたお皿が席に残る）
- **商品棚に無い物は、注文を受けてから急いで作ります**。作るあいだは長めに待ってくれますが（約3分＋α）、**遅すぎるとお客さんは帰ってしまいます**。注文票（画面左上）に「あと○つ作る」と出ます
- **販売する商品の ON／OFF はホストだけ** が変えられます（設定 → お店、またはパソコンの「販売価格」）。OFF の商品は注文されません。値段は商品ごとにだれでも決められます
- **ケーキの賞味期限は作った日を入れて2日**（3日目には消えて廃棄）。賞味期限は商品棚の値札・ケーキ・手に持ったときにいつも表示されます。冷蔵の商品棚・冷蔵庫に入れたケーキは翌日も売れます

### 冷蔵のルール（冷やさないと傷む）
- **要冷蔵の材料**（卵・バター・牛乳・生クリーム・チーズ・いちご・ブルーベリー・もも・レモン）は、常温に置くと **2〜5分で傷みます**。
  トラックの荷台は冷蔵なので大丈夫。下ろしたら **すぐ冷蔵棚** へ。小麦粉・砂糖・チョコなどの乾物は普通の棚でOK
- 半分を過ぎると「ぬるい」状態になり、そのまま棚に置くと **日持ちが半分** に。傷んだ物は使えず、捨てる（廃棄）しかありません。一晩外に置いた要冷蔵の物も傷みます
- **泡立てた生クリーム**（常温で約4分）と **クリームを塗ったケーキ**（約5分）も、常温だと「だれる・溶ける」→「傷む」。
  使うまでは **冷蔵庫**（ガラス扉・1台にケーキ6ホール）へ。冷蔵庫の中では傷まず、クリーム・作りかけは翌日まで、ケーキは賞味期限まで使えます
- 手に持った物・ねらった物には「要冷蔵・あと○分○秒で傷む」と出ます。近くにぬるくなった物があると目印が出ます
- **傷んだクリームやケーキを売ると、お客さんがお腹をこわして★1の口コミ**。評判が大きく下がります。日報にも傷ませた件数が出ます

注文票（画面左上）に待っているお客さんと残り時間が出ます。待たせすぎると帰ってしまい評判が下がります。
**失敗は売り物に残ります。** 焦げ・生焼け・ダマ・分離・ムラなどの欠点は、見た目で分かるものは売れにくくなり、
見た目で分からないもの（生焼け・分離など）は食べたお客さんの満足度が下がってクレーム・悪い口コミになり、評判が落ちます。

### 店舗レベルと解放
売った数・お客さんの満足・評判でポイントがたまり、店舗レベル（Lv1〜10）が上がります。
**材料はお菓子といっしょに解放されます**。最初に買えるのは、最初から作れるお菓子（いちごのショートケーキ・チョコレートケーキ・ベイクドチーズケーキ）に使う材料とケーキの箱だけ。新しいお菓子が解放されると、その材料が仕入れられるようになります（パソコンの「材料の注文」に、まだ買えない材料と解放されるレベルが出ます。レシピ開発でも、まだ解放されていない材料は使えません）。
レベルごとに新しいケーキや焼き菓子、上位の設備（オーブン・ミキサー・泡立て・冷却・冷蔵庫）、家具、アルバイト、増床が解放され、**Lv10 ですべての商品が作れます**。
パソコンの「レベル」（または画面上の Lv）で、どのレベルで何が解放されるかを確認できます。
レベルが上がると **お客さんの来るペースと量が増えます**（Lv1 ×0.80 → Lv5 ×1.28 → Lv10 ×1.88。Lv4・Lv7 でまとめ買い・ホールの注文が増え、一度にお店に入れる人数も増える）。

### パソコン（パソコン室：材料・家具・販売価格・設備・アルバイト・拡張・広告・収支）
- **材料**：仕入れ値は毎日、さらに注文のたびに変わります（たくさん買った物は少し上がる）。1箱10個、1回の注文は10箱まで、送料は1回 ¥500。トラックが向かっている間なら追加の注文も同じトラックに積みます（着いてから帰るまでの間は次の便）
- **販売価格**：ケーキの値段（1切れ・ホール）は自由に決められます。ただし **ケーキの相場は毎日変わり**、相場より高すぎる（130%超）とほとんど売れず「高すぎる」とクレーム・悪い口コミが入り、評判が下がります。やや高めでも、味がいまいちだと値段への文句が出ます
- **家具・道具**：厨房の家具（机・棚・冷蔵棚・在庫棚・冷蔵庫・ショーケース・商品棚・ミキサー台・オーブン・クリーム台・デコ台・洗い場・冷却ラック・ゴミ箱・レジ。トラックで大きな段ボールが届く）、お皿・ケーキの型・ケーキナイフ（1つずつ）、売り場の家具（テーブルセット・コーヒーマシン・観葉植物・BGM スピーカー）。棚などの材料でない物は少し高めです
- **設備の性能**：店舗レベルが上がると性能の高い機種に買い替えられます
- **拡張（増床）**：お店と厨房が広くなり、家具を置ける場所が増えます。家具の位置はできるだけそのまま引きつぎます

### アルバイト
- パソコンの「アルバイト」で雇えます。日給制（閉店時に支払い）
- 1人につき1つの業務（お菓子係・生地係・オーブン係・クリーム係・仕上げ係・洗い場係・仕入れ係・レジ接客）。生地係はきれいな型が無いと作れないので、洗い場係がいると回りやすくなります
- **お菓子係**：作るお菓子（ショートケーキなど）を指定すると、生地 → 焼く → クリーム → 仕上げ → ショーケースまで **1人で** 作ります（1台ずつ順番に）。「おまかせ」なら足りない物を作ります
- **仕入れ係**：トラック・床・机の段ボールを運んで、**指定した場所**（棚・冷蔵棚・机に中身を並べる／在庫棚には段ボールのまま）に入れます。「おまかせ」なら要冷蔵は冷蔵棚・ほかは棚へ。指定の場所がいっぱいなら、ほかの空いている棚へ。少なくなった材料・箱の買い足しもします
- **最大8人**。店舗Lv1 ではまだ雇えず、Lv2〜9 で1人ずつ募集できるようになります
- **人によって手際（★）がちがい**、作業の速さが変わります（同じレベルでも、手際のいい人は速い。そのぶん日給は少し高め）。働くほどレベルが上がって速く・上手になります

### 共同経営（最大4人）
- 「お店をつくる」で招待コード（6文字）が発行されます。友だちは「お店に参加」でコードを入力
- 1つのお店の資金・在庫・設備をみんなで共有。誰か1人の端末がホスト（お店の時計を進める役）になり、
  ホストが抜けても残った人に自動で引き継がれます
- プレイヤー同士はぶつかりません（すり抜けます）。名前は頭の上に表示され、ほかの人が持っている物も見えます
- 同じ段ボールやケーキを同時につかんでも、ホストが順番に処理するので増えたりしません（ホストが交代しても同じ操作は二度処理しません）

### 引き継ぎコード・データ同期
- 「引き継ぎ」でコード（12文字・72時間有効）を発行し、別の端末で入力すると同じデータに連携されます
- 連携した端末どうしは常に同期されます（スマホ ⇔ PC どちらで遊んでも最新になります）
- 「この端末以外の連携を解除」で引っ越し（移動）として使うこともできます

> **以前の「スマホのデータを PC に移すと更新されない」不具合について**  
> クラウドのデータを正とし、変更ごとに版番号（rev）を付けて「自分が持っている版からの更新」だけを書き込むようにしました。
> 別の端末が先に更新していたら取り込み直して合成（名前・きせかえ・設定は新しい方、お店の一覧は合算、記録は大きい方）します。
> アプリを閉じる／裏に回すときは未送信の変更をすぐ送り、表に戻ったときは最新を取り直します。

## 公開手順

### 1. Firebase の準備
1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成（既存のプロジェクトでも可）
2. **Authentication** → 「始める」→ ログイン方法で **匿名** を有効にする
3. **Realtime Database** → データベースを作成（ロケーションは asia-southeast1 などお好みで）
4. **Realtime Database → ルール** に `database.rules.json` の中身を貼り付けて「公開」
   - ほかのゲームと同じプロジェクトを使う場合は、既存のルールを消さずに `"rules"` の中へ `"cakeshop": { ... }` の部分だけを追加してください（このゲームのデータはすべて `cakeshop/` の下に入ります）
5. **プロジェクトの設定 → マイアプリ → ウェブアプリを追加** して表示される設定値を `js/firebase-config.js` に貼る
   - **このプロジェクト（cake-shop-fd414）の apiKey・databaseURL・authDomain・projectId はもう入れてあります**。別のプロジェクトを使うときだけ書き換えてください。`databaseURL` が空のあいだはオフライン（ひとり用）で動きます

```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "xxxx.firebaseapp.com",
  databaseURL: "https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app", // 必須
  projectId: "xxxx",
  appId: "...",
};
```

6. **Authentication → 設定 → 承認済みドメイン** に `ユーザー名.github.io` を追加

### 2. GitHub Pages
1. このフォルダの中身をリポジトリに置いて push（`index.html` がリポジトリの直下に来るように）
2. リポジトリの **Settings → Pages** で「Deploy from a branch」→ `main` / `(root)` を選んで保存
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で遊べます

`firebase-config.js` の apiKey などは公開されても問題ない値です（データの保護はルール側で行っています）。
